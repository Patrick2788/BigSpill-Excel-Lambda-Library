# Nested Array Prototypes (BigSpill 2.0)

This folder contains early prototypes exploring nested array techniques
planned for BigSpill 2.0. These workbooks demonstrate experimental
operators, rewrites of existing functions, and new approaches
to windowing, convolution, and mesh-grid construction.

These files are not part of the stable BigSpill release and may change
frequently. They are provided for exploration, testing, and feedback.


Contents:
- Nested array windowing prototypes
- Convolution and mesh-grid rewrites
- Early BigSpill 2.0 operator concepts
- Demonstrations of nested-array spill behavior
- Dedicated Secret Gist URL for import into AFE

## Compatability:
Presently, nested array support requires one of the following builds:
- Windows: Version 2610 (Build 20520.20000) or later
- Mac: Version 16.114 (Build 26092111) or later

## Advanced Formula Environment (AFE) Notice  
Some functions used in BigSpill ALPHA - including FLATTEN, HASALL, and list literals such as {  } - are not yet recognized by AFE and
will appear with red underlines. This will resolve once AFE updates. The module and functions are still able to run without issue.
